5. The numbers: data versus theory

“SD” of the sample means uses the sample version (divide by one less than the number of means). Skewness is 0 for a perfectly symmetric shape and positive when the long tail points right. The theory column for skewness is only a rough guide: the parent’s skewness divided by the square root of n.

6. What to notice

Honest note. The Central Limit Theorem is about the distribution of sample means (or sums) built from independent draws. It does not make the parent population bell-shaped, and it does not make any single sample bell-shaped. How large n must be depends on how skewed the parent is: a nearly symmetric parent needs a small n, a very lopsided one needs far more. There is no magic number. n = 30 is only a common rule of thumb, and you can test it yourself above.
