Notes

Systematic sampling caution: it takes every k-th person from a list. If the list has a repeating pattern that lines up with k (for example, every 10th person on a roster is a team captain), the sample can be badly off. In this town, the ID order has no such cycle, but real lists sometimes do. Samples use fresh random numbers each time you draw, so your results will differ from a classmate’s. The town itself is the same every time.
