4. What 95% confidence means

Common misreadings
  1. "There is a 95% chance the true value is inside this interval." Once an interval is built, the true value is either inside it or not. The 95% describes the method, not this one interval.
  2. "95% of all individual values fall inside the interval." The interval is about the single true value of the population (a proportion or a mean), not about where individual people or measurements land.
  3. "If I take another sample, 95% of the time its estimate lands inside this interval." No. Each new sample builds its own interval. The 95% is about how often intervals built this way catch the true value.
