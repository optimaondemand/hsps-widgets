📈 TOO MANY VALUES FOR A LINE
Thirty-three values is already awkward for a line plot; three thousand is impossible. When the dataset grows we give up showing each value and start showing where the values pile up. Today's two displays do that in two different ways: the histogram shows the whole shape; the box plot shows a five-number summary. They are meant to be read together — and today you will see why.
Both are drawn for numerical data. Today's example is made-up: 33 values on a 0 to 100 scale, which we will call Set A.
🏗️ THE HISTOGRAM
A histogram divides the number line into equal-width intervals called bins (or classes), counts how many values fall in each, and draws a bar whose height is that count. Two rules separate it from a bar chart: the bars touch, because the horizontal axis is a continuous number line with no gaps between the categories; and the bar's position matters, because the bins are ordered pieces of one scale.
Every value must land in exactly one bin, so we need a rule for values on a boundary. Throughout this course, each bin includes its left endpoint but not its right: the bin 40–50 holds values from 40 up to, but not including, 50, written \([40, 50)\). A value of exactly 50 belongs to the next bin.

📦 THE FIVE-NUMBER SUMMARY AND THE BOX PLOT
The five-number summary is the minimum, the first quartile \(Q_1\), the median, the third quartile \(Q_3\), and the maximum. The quartiles cut the ordered data into four parts holding about a quarter of the values each. The box plot draws them: a box from \(Q_1\) to \(Q_3\), a line inside at the median, and lines (whiskers) out to the minimum and maximum.
How to find the quartiles by hand (the “median of each half” method): order the data; find the median; split the data into a lower half and an upper half — leaving out the median itself when the number of values is odd; then \(Q_1\) is the median of the lower half and \(Q_3\) the median of the upper half.
Worked example, small set. Eleven puzzle times in minutes (constructed): 3, 5, 6, 6, 8, 9, 11, 12, 14, 15, 21. There are 11 values, so the median is the 6th: 9. The lower half (without the 9) is 3, 5, 6, 6, 8, whose median is 6. The upper half is 11, 12, 14, 15, 21, whose median is 14. Five-number summary: 3, 6, 9, 14, 21. The interquartile range, \(\text{IQR} = Q_3 - Q_1 = 14 - 6 = 8\), is the width of the box — the span of the middle half of the data.

🔍 THE SURPRISE — ONE BOX PLOT, TWO DIFFERENT SHAPES
There is a second dataset, Set B, also with 33 values on the same scale. Its five-number summary is exactly the same: 12, 40, 50, 60, 88. So the two box plots are identical. But Set B is not one hump. Counted in bins of width 5, its middle looks like two clusters — 8 values in [40, 45) and 15 across [55, 70), with only 1 value in each of [45, 50) and [50, 55). A box plot cannot show this. It hides gaps and clusters inside the box. A histogram shows them. That is why you rarely trust one display alone.

💻 CALCULATOR SKILLS · EXCEL: COUNTIFS BUILDS THE HISTOGRAM TABLE
Last lesson you used COUNTIF to count how many cells equal a value. A histogram needs to count how many cells fall between two values — two conditions at once, which is COUNTIFS (the same idea with an S). Recipe for Set A:

1. New sheet. In A1 type Value; in A2:A34 type the 33 values of Set A.
2. In C1 type Lower, D1 Upper, E1 Frequency. In C2:C9 type 10, 20, 30, … 80. In D2:D9 type 20, 30, 40, … 90.
3. Click E2 and type =COUNTIFS($A$2:$A$34,">="&C2,$A$2:$A$34,"<"&D2) and press Enter. The first condition says “at least the lower edge”; the second says “less than the upper edge” — exactly the left-in, right-out rule. You should see 1.
4. Drag the fill handle down to E9. Your column should read 1, 2, 4, 9, 8, 4, 2, 3.
5. In E10 type =SUM(E2:E9): the total check, which must equal 33 (and =COUNT(A2:A34) should also give 33). If the total is 32 or fewer, a value falls outside every bin — extend the table.

You build the actual Excel chart from this table in Week 21. In Desmos, the median of an even-sized set is one line: for the twelve puzzle times below, type (22+23)/2 → 22.5.
🤖 AI TRAINING · PROMPT → PREDICT → VERIFY
Prompt. Give an AI tool this list of counts in bins of width 10 starting at 20 and ask it to describe the histogram's shape: [20,30): 2; [30,40): 4; [40,50): 6; [50,60): 6; [60,70): 3; [70,80): 2; [80,90): 1.
Predict. Sketch the bars first. Heights rise to a peak over 40–60 and fall away on both sides: one hump, roughly symmetric, with the right side trailing off a little longer than the left.
Verify. Compare the AI's description with your sketch. Did it name the right peak? Did it call the shape symmetric, skewed left, or skewed right — and does your picture support that? Language tools often swap “left-skewed” and “right-skewed” (the tail's direction names the skew, not where the peak is). Mark every claim of its that your picture does not support.
