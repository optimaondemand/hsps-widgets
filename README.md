# hsps-widgets

Interactive widgets for the Probability and Statistics Honors (1210300) Canvas course at Optima Academy Online.

The first 18 widgets are copied as-is from [tuu-widgets](https://github.com/optimaondemand/tuu-widgets); new course-specific widgets are built here directly.

Served via GitHub Pages: https://optimaondemand.github.io/hsps-widgets/
